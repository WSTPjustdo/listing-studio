## 图片、商品资料与竞品研究（2026-10-23）

导航进入 **图片与竞品研究**。范围仍为 Amazon US 棉布手提袋。

1. 展开“接口连接”，选择本地爬虫（无需商品 API 密钥）或填写自备 Rainforest API Key；若需图片识别，再填写支持图片输入的 Chat Completions 兼容模型地址（通常以 `/v1` 结尾）、模型名称和密钥。英文生成沿用原“模型设置”，需要真实模型，demo 不会假装完成竞品优化。凭据只保存在本机数据库，不在配置响应或分享包中返回。
2. 上传 PNG/JPEG/WebP 图片（最大 3 MB），粘贴商品说明、上传 UTF-8 `.txt`（最多 15000 字符），或填写**自己的** Amazon US 链接/ASIN。图片用于外观观察和搜索提示；具体参数从商家文字及自己的商品详情页提取，保留原文依据、单位、来源和缺失/冲突提示。无需用图片证明文字参数。提取结果可编辑后保存为自己的商品；已有批量导入商品可直接在第二步选择。
3. 输入搜索词、自己的销售总价、价格浮动范围、需要比较的英文规格词及品牌/目标客群定位。通过本地爬虫或可选第三方 API 搜索最多 5 个候选，附带前 3 个商品详情。本地爬虫没有商品 API 按次费用；选择付费服务时以其计费为准。不自动翻页，地区恢复只有限重试。
4. **搜索结果不等于竞品。** 价格超出范围单独标记；缺少价格或规格资料标记待核实。价格与规格关键词命中仅是初筛，不能证明产品等价。当前不自动换算套装单价，不自动估算品牌溢价、客群或品质；商家需要核对变体、数量、优惠、品牌定位后勾选竞品池，超出价格范围的候选也只能经商家主动选择进入。
5. 查看所选竞品的标题、五点、参数和来源词条，勾选适合自己商品的词。次数仅是候选标题/五点中的商品覆盖数，不是搜索量、排名价值或转化率。当前词条为英文单词/相邻词组提取，可能包含品牌或不适合本商品的宣称，需选取。可导出 JSON 研究报告；最近 20 次检索可恢复，恢复后需重新确认竞品与词条。
6. 选择或手动修改英文风格，生成新的英文标题、亮点、五点与描述，随后自动审核。竞品资料独立传入，不作为本商品参数证据。草稿保存到原有版本系统，可打开手动修改；不覆盖旧稿，也不直接发布到 Amazon。生成任务离开页面后可从运行/版本记录查看。

默认支持本地 omkarcloud 爬虫，无需商品 API 密钥；Rainforest 作为可选服务保留，未连接 SP-API。已完成本地真实商品检索；视觉模型仍需配置，未完成真实图片推理验收。

可选环境变量：`RAINFOREST_API_KEY`、`VISION_BASE_URL`、`VISION_MODEL`、`VISION_API_KEY`。页面保存的配置优先。商品文字与图片在点击识别时发送给所配置模型；自己的商品链接与检索词发送给商品数据服务。图片原始数据不写入数据库，提取结果、来源快照、检索和生成记录在本机保存。

## 批量商品流程

首页点击 **导入商品表**，或导航进入 **批量商品**：

1. 上传 `.xlsx` 或 UTF-8 `.csv`。第一行为表头，每次最多 200 行商品、60 列、5 MB。旧 `.xls` 需另存为 `.xlsx`，公式列先粘贴为值。多工作表可选择要导入的一张。
2. 系统识别常见中文/英文列名；展开“调整列对应关系”修正映射。可以直接编辑名称等字段，或选择行号修正完整资料。未映射的列保留在本机导入记录中，不自动当作可靠商品事实。
3. 选择“生成新品英文文案”“检查已有英文文案”或“优化并检查已有英文文案”，不需要编写提示词。后两项要求现有英文标题；卖点用单元格内换行分隔。导入缺失材质、尺寸的商品仍可继续，未知信息不推测。
4. 对重复 SKU 选择跳过、更新或另存。更新时空值保留已有事实；文件内重复 SKU 不允许同时更新，避免覆盖歧义。无 SKU 自动生成行编号，不能跨文件识别重复。不同变体按不同 SKU 导入。
5. 点击“检查导入内容”，修正或排除不支持的行，再确认开始。当前范围是 Amazon US 棉布手提袋；没有品类列时需显式确认，其他明确品类会被阻止。
6. 每件商品独立处理，批量队列并发为 1。刷新/关闭页面不取消任务；本地服务需保持运行。可暂停后续商品、继续、只重试失败商品。服务重启会保留任务，已开始但中断的商品标记失败，未开始的行继续排队。修改模型类型或名称会暂停队列，确认使用当前模型后继续。
7. 导出商品文案 Excel 或待处理事项 Excel，支持未全部完成时导出。按 SKU 对应，包含状态和未解决项；同一 Listing 后续保存的新版本会体现在导出中。这是协作结果表，不是 Amazon 官方批量上传模板。

默认 demo 不调用外部模型，优化只执行确定性修复。真实模型按实际调用量计费；创建/优化通常每件两次、检查一次，格式异常可能重试。批量数据、原始行和任务结果保存在本机 `.runtime/listing-studio.sqlite`，不随分享包分发。创建商品快照在该行开始执行时写入。

## 跨商品同类问题集中处理

批次完成后，在结果区的“按问题集中处理”展开问题组，勾选商品：

- **统一审查所选商品**：自动导入本类问题及各商品自身资料，仅允许修改该类问题涉及的字段，随后复核完整文案。真实模型通常每件两次调用；demo 仅执行确定性修复。
- **预览批量修复**：逐件展示已有建议的修改前后内容，确认后排队应用并复核。没有建议或建议冲突的商品跳过并说明原因。真实模型通常每件一次调用。
- **暂不处理（保留风险）**：保留原文和问题，不表示审核通过；记录仅对当前版本生效。

每件商品独立保存新版本，失败项可单独重试；等待时若文案发生变化，会阻止覆盖并要求重新选择。记录保存在本机，刷新可恢复，Excel 导出附“集中处理记录”工作表。一个批次有运行或排队任务时，需先等它结束；暂停的队列需继续执行。

缺失资料仍需按商品补充，不会把一个商品的参数套给其他商品。补资料表格回传、导入映射自动复用尚未实现。单件文案可通过“查看文案与问题”进入已有修复流程。

## 配置 DeepSeek

推荐在页面右上角打开“模型设置”，选择“DeepSeek / 兼容接口”，填入：

| 设置 | 值 |
|---|---|
| 服务地址 | `https://api.deepseek.com` |
| 模型 | `deepseek-flash`，或服务商当前提供的其他兼容模型 |
| API Key | 在本机设置页填写自己的密钥 |

预设按 2026-10-21 的 [DeepSeek 官方入门文档](https://api-docs.deepseek.com/)核验。DeepSeek 官方域名启用 JSON 输出、非思考模式和明确的输出长度预算；其他兼容服务只发送通用聊天参数，不强加 DeepSeek 专属字段。可填写 `/v1` 前缀或完整 `/chat/completions` 地址。

也可以使用环境文件：

```powershell
Copy-Item .env.example .env
```

编辑 `.env`：

```dotenv
MODEL_PROVIDER=compatible
MODEL_BASE_URL=https://api.deepseek.com
MODEL_NAME=deepseek-flash
MODEL_API_KEY=在本机填写
```

支持 `DEEPSEEK_API_KEY` 作为 `MODEL_API_KEY` 的备选环境变量。环境配置变更后重启 API；页面保存的本机配置优先于环境默认值。

配置保存在本机 SQLite 的 settings 表，文件位于 Git 忽略的 `.runtime/`。接口仅返回“是否已配置”，不返回密钥。此版本是单机工作空间，不能直接改为公网服务使用。

真实账户联调状态见 [验证记录](VALIDATION.md)。当前验收使用真实 DeepSeek 和真实公开商品；旧模拟测试仅以 legacy-mocked 命令保留，不作为当前验收依据。

6. 查看版本对比，复制英文文案，或导出 TXT、JSON、HTML 审阅报告。

### 独立诊断与局部修复

无需逐条复制问题：在“检查与依据”点击“用 DeepSeek 审查并修复”，自动提交当前版本全部问题、原句、建议、资料缺口、完整文案和商品快照，不受分类筛选影响。真实模型会批量修正并独立复核，创建新版本；旧版本保持不变。当前修复使用真实模型，未解决问题继续保留。存在未保存编辑时先保存，历史版本需切回最新版本。

修复建议会按字段检查整组一致性：相同建议自动去重，同字段不同建议不自动合并，并显示提示。旧记录中同一字段的多个建议只能选择其中一条，避免应用时出现“修改路径无效或重复”。缺失依据的条目仍需核实。

DeepSeek / 兼容接口偶发返回非法 JSON 或不符合约定的数据结构时，会在原超时预算内自动重试一次，使用更严格的格式要求；仍失败则保留原文和历史版本。运行 trace 的 `format_retry` 记录重试及首次失败调用的信息，`usage` 为最后一次调用，首次调用 usage 位于 `format_retry.failed_attempt.trace`，如需统计总费用请合计；重试可能增加一次模型调用。鉴权、额度、截断和超时不盲目重试，Dify 工作流不自动重放。

“商品描述准确性”等问题卡片现在可直接点击“修改这段文案”，定位到字段后修改并“保存并重新检查”；有可用补丁时也可直接“预览修复”。若商品档案不准确或资料不足，点击“核对 / 补充商品资料”，保存资料后“使用当前资料重新诊断（新任务）”。重新诊断使用当前文案与最新选择的商品资料，保留原任务及其快照；补充资料不等于自动通过认证或语义审阅。

1. 进入“诊断与修复”，粘贴四类 Listing 字段，或点击“载入问题样例”。
2. 可关联商品；不关联时，事实对照明确显示资料不足。
3. 点击“开始诊断”，查看平台规则、美国宣称预审及事实质量反馈。
4. 点击原句定位字段；点击“查看依据”打开来源。
5. 勾选局部修复，预览后应用。只修改选中字段，原版本保留，并重新检查。

商品页支持手动新增棉布袋档案、修改已有资料并保存为新版本。新值标记为商家确认，既有公开来源不被冒充为新值的证明；历史 Listing 保留当时的商品快照。
