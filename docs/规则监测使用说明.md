# 四站点规则监测

在左侧「更多功能」中打开「Amazon 规则监测」。页面提供美国 US、英国 UK、德国 DE、法国 FR 的本机规则包版本、核验主题、官方信息源入口和人工变化台账。

## 登记与查找

1. 从官方页面核对站点、类目、适用商品和政策原文。Seller Central 可能需要卖家账号登录；入口可打开不代表已读到政策正文。
2. 点击「登记规则变化」，填写标题、站点、类别、变化内容和 HTTPS 来源链接，可补充产品影响。没有取得的发布日期、生效日期留空。
3. 无法核实的消息选择「待核实」。其他状态也由登记人选择，日期不会自动改变状态，保存记录不会修改审核规则包。
4. 保存后，可按站点和状态筛选，通过「查看来源」返回原页面，或删除不再保留的记录。

只核对到已有指南时，应写明「来源核对，变化待核实」，不要把既有政策当成本周新增。空白台账仅表示当前浏览器没有登记记录。

## 保存范围

记录保存在当前浏览器、当前网站地址的本地存储中，不写入商品数据库，也不会随分享 ZIP 分发。更换浏览器、电脑或端口会看到另一份记录；清除浏览器数据会清除台账。当前没有跨电脑同步或导出/导入功能。

保存失败会保留表单并提示；遇到已有记录损坏或读取受限时，页面保留原存储数据并阻止新增、删除，先备份并恢复存储后再操作。

## 能力范围

每周检查是供团队安排的人工建议。当前没有后台爬虫、已接通的定时任务、Seller Central 授权或 ChatGPT 监测结果同步。外部任务是否存在及其运行状态未知。

四站点卡片列的是当前规则包的检查主题，不代表每项法规都已实现审核或商品已合规。实际适用范围与未检查项请在「规则与来源」和对应文案审核中查看。未知商品资料继续未知；记录政策不等于商品上架通过。

## 验证

启动真实工作台并构建最新前端后，可执行 `npm run test:live:rule-monitor:browser -- --base-url http://127.0.0.1:8787`。脚本使用隔离浏览器，实时读取 FTC 官方指南，验证登记、重载、筛选、删除、存储异常和桌面/手机布局；不调用模型。测试记录不会写入日常使用的浏览器。

完整生成与复检继续按项目约定运行 `npm run test:live` 与 `npm run test:live:browser`，它们会使用本机真实模型配置并产生实际调用费用。规则监测的界面验收不替代真实模型验收。
