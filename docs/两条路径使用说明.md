# ListingStudio：从首页的两个选择开始

当前主要用于 **Amazon 美国站棉布手提袋英文 Listing**。开始前确认模型已配置，并准备真实的自家商品资料；未知参数可以留空。

**我有提示词，帮我改进**：粘贴你正在复用的提示词模板，再提供本次商品资料或选择已有商品档案。工作台会结合商品事实改进模板，随后生成并检查文案。手里已有完整文案时，也可以点“直接检查文案”。

**我没有提示词，帮我完成**：提供商品文字、链接，或在已配置图片识别服务时上传图片；也可以选择已有商品档案。工作台先识别资料，再尝试读取同类商品的公开文案，供你选择参考商品与关键词。参考内容用于整理写法与写作要求，不能证明自家商品的参数、认证或性能。

两条路径都按同样的三步完成：

1. **交材料**：提供提示词和商品资料，或直接从商品资料开始，点“下一步：确认商品信息”。
2. **确认商品信息**：核对名称、真实材质和已识别参数，需要时展开补充。确认资料及“美国站棉布手提袋”范围后，点“生成并检查”。等待时保留当前页面；报错会保留已填写内容。
3. **查看结果**：先读推荐文案，再处理待确认事项。结果会保存在“我的结果”中。

结果页主要做三件事：

- **看推荐文案**：检查标题、五点与描述是否符合真实商品。
- **处理需要你确认的事项**：查看问题、缺失资料和尚未完成的检查；需要继续修改时，点“处理问题与局部改稿”。
- **复制或导出**：使用“复制英文文案”或“导出文案”。展开“查看改进后的提示词”可复制模板；完整报告与来源也可按需展开。导出后仍需商家自行核对并提交上架。

如果 Amazon 采集遇到验证页或读取失败，页面会显示原因。你可以重新查找，主动点“改用官方公开商品参考”，或明确选择“只按自家资料继续”。官方参考当前仅覆盖已登记的 Westford Mill [W101](https://westfordmill.com/products/w101) 和 [W201](https://westfordmill.com/products/w201-premium-cotton-tote) 商品页，范围限于这两个公开页面；切换后会显示实际来源，不代表完成 Amazon 竞品采集或全市场检索。部分来源未取得时，可展开查看失败详情。

原来的导入已有文案、商品资料、台账、批量处理、诊断修复和规则与来源，都保留在 **“更多功能”** 中。日常开始任务用首页两条路径，查看已保存内容用“我的结果”。
