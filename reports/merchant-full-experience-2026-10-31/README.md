# 中国亚马逊卖家全流程体验报告

体验日期：2026-10-31，Asia/Shanghai。体验对象为当前工作区版本，生产前端由本轮隔离服务 8794 提供。角色为中国跨境运营，目标是在没有提示词和已有提示词两种情况下，把真实商品资料整理成英文 Listing，修改、复检、交接补资料并导出台账。

本轮结论：两条主路径都能产出经过独立审核的草稿，局部改稿和保留版本可用；日常经营最先需要完善的是草稿防丢、付费 A/B 结果的保存与审核、多站点台账，以及上架准备清单的处理入口。当前适合受限品类的辅助文案工作，尚不能把整条链路当作完成上架。

## 真实体验范围与结果

- 实时读取 Westford Mill W101 官方页面 https://westfordmill.com/products/w101 ，HTTP 200。材质、140gsm、38×42cm、10L、67cm 提手和 CutAway 标签均有真实原文；官方公开商品不等于用户库存。颜色、零售件数、认证、SKU、ASIN及上架事实未取得，不补造。
- 没有提示词：粘贴真实原文 → DeepSeek 识别 → 确认规格 → Amazon 检索被访问验证阻断 → 主动选择两款官方参考中的 W101 → 写作方案 → 生成 → 独立审核。生成按钮至结果约 18.2 秒，资料识别约 2.5 秒。
- 已有提示词：输入本轮体验者编写的真实写作要求（不是商家私有模板）→ 选择同一真实商品档案 → 确认 → 写作方案 → 生成与独立审核。新增任务 listing-f4ae783b-4666-4119-b18a-0ffafe46fd49@1。
- 对自动路径第四条标签卖点提出中文修改要求，删除原文没有直接说明的 “with your own tag or print” 延伸；真实改稿并独立审核保存 V2，其他字段保持原样。继续真实复检保存 V3。
- npm run test:live 完成本轮独立官方 W101 生成、修订、补真实规格后三版闭环；npm run test:live:browser 完成另一隔离库中的真实复检、旧版本保护、证据展开及 HTML/TXT/JSON/纯文案导出。
- 实际下载补资料交接 XLSX、纯文案 TXT；台账实际固定草稿 V3 并下载 Excel。台账 SKU/ASIN 留空，未登记已上架。没有供应商真实回传材料，本轮未伪造回填并声称供应链闭环完成。
- A+ 参数素材、协同看板、上架检查、变体审核、证据台账、VOC 和搜索词入口均进入查看。A/B 使用本机真实 DeepSeek 生成三版，见下文丢失问题。没有真实差评和 ABA 原件，没有用占位示例做商家验收。
- 390px 手机首页文档宽度为390px，无横向溢出；手机上重复复现了导航丢草稿。

## 体验中还需商家人工把关的地方

自动初稿第四条写了“with your own tag or print”，本次输入的标签原文只直接说明易于rebranding，审核仍给0项内容问题。本轮已手动要求删除并复检。官方页面另有印花面积不等于本次确认资料已经包含了印刷能力；建议对这类语义延伸做更明确的证据提醒。这是本次样例观察，不能据此推导普遍漏报率。

0项问题并不等于可上架。主工作台有未确认品牌/颜色/零售包装提示，但引导结果的复制与导出先于待确认项。建议在主要交付按钮旁同时显示“未确认资料数量/未检查项数量/未连接Seller Central”，让运营在交付当下看到状态。

## 真实模型与失败记录

本轮共22次真实DeepSeek响应，164,145 tokens；6次MODEL_INVALID_JSON均保留。全部响应有实际请求ID、模型、耗时和用量；账单金额未知，没有用tokens推算价格。A/B产品自身没有台账，本轮用隔离服务的真实网络只读元数据补证：6e4b1d30-16d8-4ea6-a545-b72e65199025，deepseek-flash，3165ms，1800 tokens，没有模拟上游。

模型请求全表见model-call-ledger.json；标准流程见standard-live.json；浏览器真实复检见browser-live.json；两条首页路径真实文案见guided-results.json；A/B关闭丢失、面板、导出体验见delivery-experience.json；台账实际保存/下载见library-browser.json；局部改稿见browser-revision.json。

成功不掩盖失败：最初改稿脚本使用按钮可见文字而非aria-label导致定位超时，未触发模型；最初已有提示词路径把“导出文案”链接当按钮导致脚本失败，后来从已保存真实记录恢复并实际下载，没有重复生成收费。交付脚本中遇侧栏拦截台账点击，干净页面重试成功；初期全页截图出现侧栏覆盖，正常视口测得侧栏200px，尚未确认稳定产品触发条件，作为待定位现象保留，不列为已确认缺陷。
