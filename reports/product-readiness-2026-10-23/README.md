# 产品改进交付与真实验收

日期：2026-10-23（Asia/Shanghai）。

本轮实现采购补资料 Excel 导出、回传预览及运营选择确认；材料原子保存并保持待核验。生成入口增加目标买家、场景、购买顾虑、风格；对话修改可由服务端限制为标题 / 亮点 / 描述。增加相同业务输入的审核结论比较；模型漏引用映射归为系统检查异常，不转给采购重复补资料。

## 真实结果

- 构建通过。test:live 最终独立流程生成、修复、补规格复检完成，最终 0 项发现；颜色和零售包装继续待补。表达方向已保存并传给真实生成及审核请求。
- test:live:browser 最终真实复检与浏览器检查完成。当前工作台 W101 V16 仍有 1 项检查异常及 2 项资料待补，不称为全部审核通过。
- test:live:handoff 的两轮对话与同输入复检实际运行见 acceptance.json；transfer-acceptance.json 是最终代码上的浏览器导出、回传、确认及错误防护验收，无额外模型调用。只改标题 / 描述时范围外字段未变化，旧快照保留。
- test:live:evidence 使用已有真实官方原文复检，保留待核验和未知零售件数。test:live:library 使用已存真实文案导出，两张表的标题、五点和描述逐项核对，无额外模型调用；未在桌面 Excel 实机打开。
- 28 个已存真实版本做了程序重放检查，不是新的模型验收，也不是准确率评测。

## 保留的失败和分歧

共记录 33 次真实响应、215,760 tokens（含排错、格式重试与复验；金额未知）。每次请求 ID、模型、耗时和用量见 real-api-summary.json。

官方商品页有一次 30 秒超时，见 source-timeout.json；后续重新实时读取成功，没有用缓存冒充成功。DeepSeek 有一次连续两次非法 JSON 导致任务失败，见 model-format-failure.json；旧正文与版本未覆盖，后续人工触发复验完成。

相同正文与资料确实出现审核结论变化，V8→V9 的实际分歧被识别并标为需人工核对。不能据此声称模型稳定性问题已消除。当前未解决项包括模型遗漏部分证据映射、变体颜色和零售件数，详见当前版本结果。
