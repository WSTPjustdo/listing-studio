1. VOC / A/B 直接调用模型，尚未接入既有请求台账，响应缺少请求 ID、实际模型、耗时和用量，也没有独立审核。它们不满足项目当前真实验收记录约定，不能以 `model_used=true` 代替验收。

3. 搜索词解析直接取首列。对于排名列在前的 ABA 报告，代码会把排名当搜索词；普通子串匹配也存在误覆盖。没有真实报告供本轮验证，不能声明真实 ABA 导入通过。
4. 岗位面板只读，源文档与说明中的“可人工调整”尚无对应 UI 或保存逻辑。

这些是源代码审阅发现的具体限制；本轮只修复同步后已实际复现的手机布局问题，没有用自造输入替代真实商品或验收资料，也没有修改或伪造此前模型结果。
