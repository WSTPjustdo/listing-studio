# 游园会：保温杯模拟商家演练

本套材料不依赖真实商家数据。以 THERMOS 公开商品资料为样例，模拟运营拿资料、看英文、发现问题、改稿和复检的业务过程。问题稿是人工植入的错误；AI 输出和调用记录来自本机已有 DeepSeek 配置的实际付费请求。没有真实商家 SKU、库存、订单或上架结果。

## 现场打开

Edge 入口已在本机实际启动并确认出现演示页窗口；本次入口调整没有新增模型调用，记录见 [edge-entry-acceptance.json](edge-entry-acceptance.json)。

双击项目根目录 `start-fair.cmd`，会用 Microsoft Edge 新窗口打开已保存的离线演练。本机桌面也有「游园会演示（Edge）」快捷方式；分享给其他电脑后，完整解压并使用包内 `start-fair.cmd`。页面自包含，可断网浏览，无需安装依赖、启动服务或等待模型。也可在 Edge 中直接打开本目录 [index.html](index.html)。每一步都显示给观众的操作提示；点击“揭晓审核”只展示已保存的真实审核结果，不发起新的 AI 请求。

要切换到原有完整功能，双击项目根目录 `start-workbench.cmd` 或本机桌面的「本地工作台（Edge）」，打开 [本地工作台](http://127.0.0.1:8787/)。服务已运行时直接打开，未运行时自动调用原 `start-local.cmd` 并等待就绪。工作台使用本机已有模型配置，实际生成、修改和复检会调用模型；离线演练继续保留，两种入口可分别打开。正式工作台仍按现有棉布袋品类规则执行，本页保温杯材料不扩大其范围。分享包不含本机密钥与数据库，其他电脑需自行配置工作台。

五件材料：

1. [商品资料](product-source.md)：官方页面实际摘录、15 项已知、10 类未知、型号变体与来源时间。尺寸单位、两侧钢材牌号、食品接触检测等未取得资料保留未知。
2. [预先准备好的英文 Listing](listing-en.txt)：最终修改并独立复检的版本；标题、简短 highlights、五条卖点、描述齐全。
3. [明确问题的风险稿](risk-draft-en.txt)：人为植入 48 小时保温、无条件防漏、FDA 认证/健康保证；不冒充品牌或真实商家原文。
4. [完整案例与修改对比](case.json)：原始生成、问题稿、改稿、复检和历史失败记录；展示页自动逐字段对比问题稿与最终版本。
5. 成功复检：最终请求 `21fd88b2-179e-4ea0-98e0-56e9fd135528`，`deepseek-flash`，耗时 5,402 ms（含格式失败后的真实重试），三项文案检查通过、0 条发现，范围外事项为 `not_checked`。

## 90 秒讲解和观众操作

| 时间 | 展示内容 | 请观众做什么 |
| --- | --- | --- |
| 0–15 秒 | 模拟商家资料卡 | 找到容量、材质和官方保温时间，区分已知与未知。 |
| 15–30 秒 | 已准备好的英文 Listing | 看标题和一条卖点，确认资料能变成英文文案。 |
| 30–50 秒 | 人工问题稿 | 找出“48 hours”“in any condition”“FDA certified”中的问题，再点“揭晓审核”。 |
| 50–70 秒 | 修改前后 | 看错误如何删除、条件如何保留、哪些资料仍未取得。 |
| 70–90 秒 | 已保存的成功复检 | 查看最终文案、请求信息和未核查范围，点击“重新开始”交给下一位观众。 |

人多时只展示第 3、4、5 步。网络不好时继续本页；若讲解实际在线工作台的新任务，按真实状态说明“仍在运行”或具体失败，不把本页历史结果说成刚刚生成。

## 真实模型记录与精度修正

保温杯准备共 **8 次真实响应、49,843 tokens**，其中 2 次 JSON 格式失败均保留并实际重试。逐次请求 ID、模型、耗时、用量、错误码见 [case.json](case.json) 的 `calls`。没有模拟返回。

人工复核发现初稿把 `18/8 stainless steel construction` 放大成内外壁各为 18/8，第一次模型复检没有报出。该次“0 发现”已标为被后续人工复核否定的历史记录；随后真实改稿并独立复检，最终改为有来源的 `18/8 stainless steel construction`。原始 [generated-en.txt](generated-en.txt) 仅作追溯，包含已修正的问题，不作为现场可交付稿。展示页第 2 步使用最终复检稿。

复检绑定最终文案 JSON 的 SHA-256：`ce4a4ba471a79f035312f7c4f5f86a2e1b3547e3e669cbfb58bf1f1b482c8d66`。复检证明的是文案与厂家公开资料的一致性，不证明实际保温/防漏性能、食品接触法规、品牌销售授权、完整保温杯品类规则或 Amazon 上架通过。当前正式工作台的品类规则仍为棉布袋。

官方来源首次发现过程有 404/429，最终以明确 variant URL 的实时 HTTP 200 为依据；失败和快照哈希见 [product-source.json](product-source.json)。现场不依赖重新抓取官网。

## 调试与复现

现成材料不会自动调用模型。开发时：

- `npm run fair:build`：从已保存的公开资料与真实结果重建展示页，不调用模型。
- `npm run fair:check`：验证真实结果关联、离线桌面/手机交互和加载情况，不调用模型。
- `npm run fair:prepare -- --real-api --resume`：继续尚未完成的准备，仅缺失步骤调用模型；已有完整案例直接复用。重新制作一套前先另存已有报告，不在现场删除历史或反复生成。

原有工作台的 `npm run test:live` 与 `npm run test:live:browser` 本轮均实际执行，报告见 [workbench-acceptance.md](workbench-acceptance.md)。13 次真实响应、93,614 tokens，保留 5 次格式失败；这是原有 W101 棉布袋流程的验收，不是保温杯品类验收。

离线展示完成 **83 项**真实浏览器检查，覆盖 1440px 桌面与 390px 手机、五步切换、观众提示、揭晓审核、最终英文复制、全字段对比、始终可见的下一步、键盘、重置、打印和结果哈希关联。无外部网络请求、无页面错误；本机已有浏览器单次加载约 0.1–0.2 秒，不代表在线生成耗时。精确测量与截图见 [page-acceptance.json](page-acceptance.json)。构建与严格交付文档审计通过。

本轮合计 21 次真实响应、143,457 tokens，7 次格式失败保留。没有真实商家、真实上架或全新设备验收。
