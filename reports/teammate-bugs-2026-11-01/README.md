# 队友 Bug 修复与真实验收（2026-11-01）

本轮逐项处理队友报告中的 12 个问题：

- 生成与 A/B 变体轮询等待服务端终态；单次状态请求有 15 秒网络保护，网络暂时失败时保持运行锁并提示不要重复提交。
- 资料区编辑不再把已采用的商品资料整体回滚；手工补写、已采用来源和跨批次来源会保留。再次采用只替换可明确识别的原资料片段。
- 批量页遇到浏览器遗留的不存在批次 ID 时保留历史列表、清理无效选择，不再循环 404。
- 统一请求 ID 的安全上下文与局域网 HTTP 降级生成；规则登记、批量问题和变体生成都能在非安全上下文继续工作。
- 根组件加入错误边界，显示有限错误摘要和重新加载入口。
- 主模型设置支持清除全部模型密钥；空超时按 60 秒处理，保存前限制 5–180 秒并给中文提示。
- Dify 保存不会用空字段覆盖兼容接口地址与模型；历史空配置会恢复非密钥默认/环境值，已清除的密钥不会复活。
- 引导页相同来源输入返回再进入时复用已有分析，不重复付费；参考商品、关键词和单词长度在前端提前阻断。
- 重复素材文件明确提示，失败提示不会被空错误清掉。
