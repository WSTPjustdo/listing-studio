# 商品 Listing 台账与补证交付（2026-10-23）

- 入口：工作台侧边栏「Listing 台账」。商品生成或诊断后自动出现在台账候选列表；无文案的商品不可导出。
- 管理：搜索商品、SKU、ASIN，筛选草稿 / 待上架 / 已上架。SKU未知可留空；手动登记已上架须填真实ASIN和日期并确认。未连接Seller Central，不验证或执行实际发布。
- 版本：台账保存固定的任务与版本。后续复检不会替换；资料或规则已更新会提示需复检。
- 导出：选择商品 → 导出所选Excel。首表「Listing 文案」含商品ID、SKU、英文标题、亮点、所有要点、描述、版本与上架登记；次表「审核与来源」含发现、缺失资料、待核验材料、原始来源和实际模型请求ID。长文本超过Excel单格容量时完整分片到续页，不静默截断。这是管理表，不是Amazon批量上传模板。
- 补证：在审核页点「核对 / 补充商品资料」，选择具体问题或缺失资料，记录来源原文、出具方、链接和适用型号，保存商品新版本后复检。未提交材料阻止复检；来源与商品版本原子保存，拒绝过期、重复和错配提交。
- 原文材料保持 submitted_unverified，不自动确认规格、认证或性能。装箱数量没有写入零售件数。原文/关联问题随HTML、TXT、JSON及台账Excel保留，纯英文文案TXT不混入内部材料。
