# “100% 棉”误报与复检失败修复（2026-10-31）

本轮针对用户截图中的材质误报，以及“应用并重新检查”和写作方案未完成的问题。保留工作区已有改动，未提交或移动 Git 标签。公开商品来源为 [Westford Mill W101 官方页](https://westfordmill.com/products/w101)，模型使用本机已有 DeepSeek 官方配置。中文档案“100% 棉”是官方“100% Cotton”的等义登记，不代表取得商家库存、包装或上架证明。

## 根因与修复

- **材质误报已精确复现。** 原 `parseComposition('100% 棉')` 返回空成分表，`compareFiber` 随后错误断言“商品资料的材质『100% 棉』里没有棉”。现在中文明确成分与英文 cotton 共用对照，完整读取 100%、100.0%、100 %；0%、10% 等真实数值冲突仍保留。成分无法识别时转人工核对，不把解析失败解释为不含某纤维。未筛除模型给出的真实问题。
- **模型连接处理补强。** 仅对可确证尚未建连的 DNS、拒绝连接、连接超时等错误，在原总时限内重连一次。请求发出后的断流、响应体中断及未知分支不自动重放；Dify 工作流不重放。错误和台账记录允许名单内的底层错误码、发生阶段与重连情况，不保存原始错误消息、请求地址、请求体或凭据。
- **响应体失败分类修正。** 读取响应时超时或断流不再被当作 JSON 格式错误而触发额外付费格式重试；已收到的 HTTP 拒绝状态保留。内部处理异常单独记录。
- **删除卖点后的复检卡点已定位。** 本轮浏览器两次实际应用同一模型补丁，均因模型将保留编号的空卖点槽写成 `original=""` 问题而失败。原始响应确认其指向 `content.bullet_points.b2`；这不符合“问题必须引用非空原文”的契约。审核输入现在只提交有文字的卖点，非空原文不改写，保存的版本仍保留原编号和空槽；写作请求仍保留完整编号供局部改稿。未放宽返回结构，也未删除真实审核问题。
- **格式失败可追溯。** 结构失败保留安全的字段路径与校验错误码，格式重试向模型反馈具体失败字段及字段约束。上述两轮共四次实际失败响应均保留，不保存为成功版本、不回退演示模式。

审核提示与参数关联均已更新版本标识，避免把不同算法下的结论当作相同输入的稳定性对比。对“纯棉”“全棉”“棉布”等尚未支持的写法保留人工核对，不推断成分比例。
