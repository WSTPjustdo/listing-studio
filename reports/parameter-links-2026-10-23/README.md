# 商品参数与来源的程序关联

日期：2026-10-23（Asia/Shanghai）。

## 解决的问题

此前相同真实文案“Westford Mill W101 cotton tote bag.”在 V8 返回了模型引用，V9 与 V16 等版本遗漏引用，导致检查结果随模型变化。本轮按字段、原文片段、单位、商品快照和已记录来源建立确定性关联；模型漏返回 claim_map 不再使这些已支持参数报错。旧版本保持原样，没有重写历史。

程序关联只说明参数与记录一致，不证明整句语义、来源真实性、认证、性能或实际库存。材质词匹配只说明对应材质，不向文案增加百分比。整句含义、限定条件和复杂宣称继续由模型及语义规则审阅。

## 已实现

- 材质 / 百分比、品牌、已确认颜色、克重、宽高尺寸、容量、提手长度和已确认零售件数的字段关联。
- 精确 mm / cm / 英寸、ml / L 换算，保留宽高轴顺序，不自行容忍近似舍入。官方其他单位如 4.1 oz/yd² 仅在商品已有该原文时按空白格式归一关联，不自行推导等价。
- 关联保留原文位置、识别方法、商品版本、事实状态和来源 ID。平台规则、监管指引、待核验材料及演示来源不能作为参数依据。
- 容量不证明承重；克重不证明单件重量；印刷 / 物流尺寸不证明袋身尺寸；装箱数不证明零售件数。否定、限定、不一致和未识别数值保留核对。
- 页面和 JSON / TXT / HTML / 台账 Excel 保留逐项关联，支持查看实际来源。

## 验证结果

- npm run build 通过。
- npm run test:live 使用实时官方 W101 和真实 DeepSeek，生成、修复及补规格复检最终 0 项发现，颜色和零售包装仍待确认。
- npm run test:live:parameters 实际执行两次正文不变的付费复检，逐项参数关联一致，原有身份句不再报引用遗漏；页面来源、390px、TXT / HTML / JSON 已检查。
- npm run test:live:browser 最终复验完成，工作台当前 V20 为 0 项发现，2 项资料待补；不代表平台审批或法律合规保证。
- 台账导出对照真实文案，新增参数列已实际读取并核对来源 ID。未在桌面 Excel 实机打开。
- 18 项受控文本边界探测，及 31 个真实历史版本的程序重放。受控语句是算法探测，不是商品真实宣称或模型输出，不替代以上真实验收。

本轮 13 次真实响应、89,767 tokens，包含格式重试及复验，不是常规单件成本，金额未知。请求 ID、模型、耗时和用量见 [实际调用](real-api-summary.json)。

## 保留的失败和限制

启动验证时曾早于本地服务监听，发生一次连接拒绝，无模型调用，见 startup-connection-failure.json。一次真实复检连续两次返回非法 JSON，任务失败且旧版本未变，见 model-failures.json；后续人工触发复验完成，没有回退演示。参数关联不解决模型 JSON 格式稳定性，也不保证语义检查永不误报或漏报。

现阶段只覆盖当前棉布袋常见字段，未识别表达保持待核对，不把全部数字相同当作支持。颜色、零售包装没有商家确认，仍未知。公开商品验证不代表商家实货试用、供货授权、库存或 Seller Central 发布。
