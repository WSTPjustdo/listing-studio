# Apple 风格界面优化（2026-10-31）

本轮按用户要求加入柔和圆角、磨砂半透明材质、点击反馈与过渡动效，保留已有绿色主色。导航/顶栏采用模糊与饱和度材质，内容卡片使用较高不透明度保障阅读；普通卡片 16px、首页路径卡片 20px、弹窗 24px、主按钮 12px 圆角。标题字距恢复正常。

按钮按下缩放为 0.98，卡片悬停轻抬 2px，侧栏收展使用 280ms 缓出，弹窗 280ms 进入、170ms 退出。尊重系统“减少动态效果”和“降低透明度”：关闭动画/位移，移除磨砂模糊并恢复实底。键盘焦点可展开折叠侧栏，鼠标点击收起后移开不会因焦点残留而一直展开。
