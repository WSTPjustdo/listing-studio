# 亚马逊模板与工厂零散素材接入

2026-10-31。新增首页亚马逊批量模板入口，以及两条引导路径中的多文件材料区。用法和范围见 [使用说明](../../docs/批量模板与工厂素材导入.md)。

## 实现

- 亚马逊 Excel/TSV 支持经典表头、新版属性路径、分列/重复卖点列、父子 SKU 与变体映射；多站点或语言列冲突要求人工映射。UTF-16 LE/BE 原格式导出保留原编码，SKU 前导零及原始列保持。
- 工厂材料支持 DOCX、PDF、XLSX、CSV、TSV、TXT、中英文截图及图片文字。保留文件摘要、页码/段落/表格位置、失败原因、原文及人工更正。
- 先确认同一商品，再让本机 DeepSeek 整理；材料提取不直接创建商品。最终档案、生成与审核来源快照、报告导出保留材料来源；纯文案导出保持可用。

## 验收口径

真实来源为当次实时取得的 [Westford Mill W101 官方商品页](https://westfordmill.com/products/w101) 和该页链接的 [官方规格 PDF](https://westfordmill.com/print/pdf/node/468)。文字是官方原文提取，TSV 为此前明确标记的公开商品与真实模型文案衍生表；不冒充真实商家库存、卖家 SKU 或 Seller Central 下载的官方模板。

标准 `npm run test:live`、`npm run test:live:browser` 在最终模型输入修正后均重跑通过。新材料 PDF/TXT/TSV 实际提取 → DeepSeek 整理 → 公开参数确认 → 写作方案 → 文案生成 → 独立审核 → JSON/TXT/HTML/改稿单/纯文案导出完成。品牌、颜色和零售包装保持未知；最终当次审核未发现问题，不代表平台审核通过。

本轮共 **28 次真实 DeepSeek 响应、394,590 tokens**，包括 **8 次格式失败及其真实重试**。请求 ID、模型、耗时、用量及未解决项见 [完整模型台账](model-acceptance.json)。标准命令前后两次执行、材料初次完整流程和压缩输入后复测均计入，未隐藏为修复与复验产生的用量。未取得服务商账单，不估算人民币费用。独立脚本未记录实际派发时刻的请求保留 `at=null`，另外保留已取得的版本保存时间。

工程检查包含解析、来源保留、编码、模型请求投影、引导及导出隐私，共 **65 项通过**；原批量边界 **20 项通过**；构建和交付对账通过。另一次可选严格契约探针仍被原有 `scripts/collect-listings.mjs` 的硬编码上限阻止，保留在 [工程记录](engineering-checks.json)，未作为通过项。这些工程检查不等于真实商家验收。

首次图片 OCR 初始化失败，保留 `MATERIAL_OCR_UNAVAILABLE`；本机访问默认 CDN 和 GitHub 镜像出现连接失败。改为从已锁定 npm 中英文语言依赖读取本地资源。首次接入本地资源时，Tesseract 7 的对象式语言参数引发进程异常，改为本地目录与语言代码调用；小字截图曾将 140 误读为 WM0，加入保留原图的像素放大后重测。

[最终 OCR 结果](ocr-local-resources-retry.json)：真实官方 PDF 页面截图 781 字符、真实 DeepSeek 整理后的中文工作台截图 245 字符均可用，38/42/140/67 等数值读取；无备注的官方实拍照片为 `needs_input`、0 字符，没有凭外观补参数。本次三图提取 1,705 ms，不调用付费模型。首次失败、进程异常和小字误读分别保留于 [首次记录](ocr-first-attempt.json)、[语言参数异常](ocr-worker-object-failure.json)、[小字误读](ocr-small-text-misread.json)。中文截图来自真实页面裁图，原图和裁切坐标保留，不冒充微信原件。

标准浏览器首次执行因隔离库未复制商品旧版本，过期版本检查得到 404 而非预期 409；补齐已有真实商品历史后重跑通过。材料浏览器首次执行遇另一任务正在 OCR，明确返回 `MATERIAL_BUSY`；这次记录保留，不作为通过结果。

标准浏览器初次成功执行使用既有真实 DALIX 档案，该档案深度未确认，三处三轴尺寸待复核仍保留于 [初次结果](standard-browser-initial.json)。最终浏览器复验采用本轮新导入的 W101 资料，不能据此宣称旧 DALIX 问题已解决。

[材料浏览器结果](browser-acceptance.json)：两条路径真实上传、确认、纠错、来源位置、移除后的失效重确认均通过；桌面和 390px 手机 10 项宽度检查通过，无页面错误，并实际进入一次 DeepSeek 参数确认页。没有确认商品时生成保持禁用。

完整流程还暴露两项问题，已修复后真实复验：改稿工作单未带材料来源，现与其余审阅导出一致保留文件/摘要/页码；原始材料被多处重复序列化，使一次生成输入达 126,890 tokens。现仅向模型发送采用事实和精简来源，完整原文仍存档，同一公开商品复测输入为 12,554 tokens，实测减少约 90.1%。前后两次使用量与审核格式失败分别见 [初次流程](materials-first-workflow.json) 和 [最终流程](materials-compact-workflow.json)。
